Offline • monitor + keyboard • one internal disk

Install wired

This USB installs a prebuilt, minimal NixOS system without Ethernet. Nothing touches the internal disk until you run one command, select the disk, inspect its identity, and type an exact erase phrase.

What the finished machine will do

  • Boot unattended as wired after the USB is removed.
  • Obtain Ethernet automatically through DHCP.
  • Advertise wired.local on the home LAN.
  • Start SSH automatically and accept the dedicated desktop key.
  • Keep an offline snapshot of this dotfiles repo at /etc/wired/dotfiles.

1. Boot the USB

  1. Connect the monitor and keyboard. Leave Ethernet disconnected.
  2. Insert the Toshiba USB and turn the ThinkCentre on.
  3. If it does not boot the USB, restart and press F12 repeatedly, then choose the entry beginning with UEFI for the Toshiba USB. Press Enter.
  4. At the NixOS menu, leave the first/default entry selected and press Enter. Waiting also selects it automatically.
  5. Wait until the text console shows a prompt similar to nixos login:. Log in as nixos; the live installer normally needs no password. This custom image loads the Turkish Q keyboard layout automatically.

2. Confirm UEFI, then start

Type this and press Enter:

test -d /sys/firmware/efi && echo UEFI

You must see UEFI. If you see nothing, stop and reboot through the F12 menu using the UEFI USB entry.

Then type:

sudo wired-install

3. Select the internal disk

The installer prints a disk table. Identify the internal, non-removable disk:

  • RM must be 0.
  • The Toshiba installer USB has RM 1 and must never be selected.
  • The internal disk will commonly be /dev/nvme0n1 or /dev/sda. Use the displayed model, serial, transport, and size—not the example name.

Type the complete path requested by the prompt and press Enter.

The installer prints a FINAL TARGET block, including the proposed layout: a 1 GiB FAT32 EFI partition and the remaining space as one unencrypted ext4 root partition. There is no dedicated swap or separate home partition. Read it twice. If the disk or layout is not what you want, press Ctrl+C.

The next confirmation permanently erases every existing partition and file on that selected disk.

If the target is correct, type the exact phrase printed on screen—for example:

ERASE /dev/nvme0n1

4. Let the offline install finish

The script performs seven labeled stages: partition, format, mount, hardware capture, and installation. It does not need Ethernet.

At the final stage it asks you to set a local recovery password for berkerz. Type the password, press Enter, then type it again. No characters appear while typing; that is normal.

Do not power off until you see INSTALLATION COMPLETE. If any command reports ERROR or exits early, leave the machine on and photograph the full screen; do not rerun with a different disk.

5. Shut down and move it

At the prompt type:

poweroff
  1. Wait until the ThinkCentre is completely off.
  2. Remove the Toshiba USB.
  3. Move the machine beside the router.
  4. Connect Ethernet and power, then press the power button once.
  5. Give it roughly two minutes for its first headless boot.

6. Connect from this desktop

In a terminal on this computer:

ssh -i ~/.ssh/id_ed25519_wired berkerz@wired.local

On the first connection, confirm the new SSH host key by typing yes. The dedicated key should log you in without asking for the account password.

If wired.local does not resolve, find the new wired lease in the router interface and substitute its 192.168.1.x address:

ssh -i ~/.ssh/id_ed25519_wired berkerz@192.168.1.X

7. First remote checks

hostname
ip -4 -brief address
systemctl is-active sshd avahi-daemon
ls -la /etc/wired/dotfiles
ls -la /root/wired-generated-config

The expected hostname is wired; both services should print active. The generated hardware configuration is preserved for integrating the real host into the main flake. From this point onward, we continue together over SSH and replace the bootstrap with the full GitHub-backed configuration.
